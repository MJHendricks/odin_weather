# Weather

## Overview
"odin_weather" is a web application designed to provide real-time weather information for a given location. The application utilizes the Visual Crossing API to fetch weather data and displays it in a user-friendly interface.

## Features
- **Location Input**: Users can enter any city in the world.
- **Weather Retrieval**: The application fetches and displays the current weather information, including temperature, description, and date.
- **Temperature Unit Toggle**: Users can toggle between Fahrenheit and Celsius for temperature display.

## Usage
Follow these steps:
1. **Open the Application**: open index.html
2. **Enter Location**: In the application, enter the desired location using the text input field or address bar.
3. **View Weather Information**: Once the location is entered, the application will fetch and display the weather information.
4. **Toggle Temperature Units**: If you prefer, you can toggle between Fahrenheit and Celsius by clicking the "toggle" button.

### Note
The application requires an internet connection to access the Visual Crossing API for weather data. If you encounter any issues, ensure that your internet connection is stable and that the API is accessible.
